# GlideFix

**GlideFix** is a native macOS Menu Bar application built in Swift (SwiftUI + AppKit + CoreGraphics) that solves hardware and scrolling usability issues when external Bluetooth or USB mice with notched scroll wheels are connected to macOS.

---

## The Problem
macOS couples the scroll direction of external physical mice to the built-in MacBook Trackpad ("Natural Scrolling") and processes notched scroll wheel increments in discrete, jerky line jumps.

## The Solution
GlideFix delivers:
1. **Independent Scroll Direction Inversion**: Inverts external notched mouse wheels while leaving MacBook Trackpads and Apple Magic Mice completely untouched.
2. **120Hz/60Hz Momentum Smooth Scrolling**: Converts discrete wheel ticks into buttery-smooth, pixel-interpolated momentum scrolling with exponential damping physics.
3. **Zero-Lockup Engine**: Sub-microsecond HID event inspection, watchdog recovery, and 0.0% idle CPU usage.

---

## Technical Architecture & Safety Guardrails

### 1. Zero-Lockup `CGEventTap` Engine
- Listens strictly to `CGEventMask(1 << CGEventType.scrollWheel.rawValue)` at `.cghidEventTap` via `.headInsertEventTap`.
- **Watchdog Recovery**: Automatically recovers if macOS disables the tap due to timeout (`.tapDisabledByTimeout`) or user input (`.tapDisabledByUserInput`) via `CGEvent.tapEnable(tap:enable:)`.
- **Sub-Microsecond Callback**: Event inspection and decision take under 5 microseconds, avoiding HID thread starvation.

### 2. Device Differentiation (Trackpad vs. External Mouse)
- Inspects `event.getIntegerValueField(.scrollWheelEventIsContinuous)`.
- If `!= 0`, the event originates from a Trackpad or Magic Mouse and is passed through untouched (`Unmanaged.passUnretained(event)`) immediately.
- Only discrete physical notched wheels (`scrollWheelEventIsContinuous == 0`) are intercepted.

### 3. Infinite Loop Prevention (Synthetic Event Tagging)
- Synthetic events generated by the smooth scroll interpolator are tagged with magic identifier `0x474C4944` (`"GLID"`) in `.eventSourceUserData`.
- The event tap callback checks for `0x474C4944` at the very top of the callback and immediately passes it downstream.

### 4. 120Hz Physics Interpolation
- Discrete ticks are swallowed (`return nil`) and fed into a thread-safe velocity accumulator.
- A high-priority serial queue runs a `DispatchSourceTimer` at 120Hz (8.33ms interval).
- Applies exponential decay / friction (`velocity *= dampingFactor`).
- Emits pixel-unit continuous scroll events (`CGScrollEventUnit.pixel`).
- Automatically suspends the timer when remaining velocity drops below `0.5` pixels, guaranteeing **0.0% idle CPU usage**.

### 5. App Exclusion & Permissions
- Automatically tracks the frontmost application via `NSWorkspace` notifications.
- Excluded apps (CAD, Blender, games) bypass smoothing while preserving inversion if desired.
- Accessibility permissions are cleanly polled every 1.5s only during onboarding and activated seamlessly without restarting the app.
- Emergency safety kill-switch shortcut: `Cmd + Option + Shift + M`.
